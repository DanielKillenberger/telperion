# Bounded follow-up after native foliage checkpoint

Host design, 2026-09-20. Run only after the first GPU candidate has its correctness checks, four hero images and checkpoint. This does not relax R1-R5 or count as qualification.

The seed-1 native GPU experiment measured wood construction at roughly 227 ms for spruce and 280 ms for oak. Spruce descriptor preparation costs roughly 142 ms. The wood and attachment loops evaluate the same angular sine/cosine for every ring. For zero twist they also repeat the same lobe profile calculation. Cache those values once per build in a small shared surface helper. Preserve the original operation order and fixed transcendental functions. Keep per-ring phase/profile evaluation for nonzero twist. Do not change topology, normals, winding, coordinates, triangle rejection or fallback directions. Allocation failure remains explicit. Test zero and nonzero twist, lobes and signed zero against the prior ring calculation, then compare complete specimen fingerprints. Measure end-to-end benefit instead of inferring it from removed calls.

The CPU-output GPU example currently constructs a full renderer solely to obtain a generator. CPU-output consumers need the device and compute pipelines, but no renderer, frame or render pipelines. Add an explicit standalone CPU-output constructor or equivalent narrowly typed entry point. Keep renderer-bound resident results tied to their original renderer. A standalone generator must reject resident delivery before generation rather than producing a result no renderer can accept. Retain normal CPU fallback, input validation and named errors. Compare the same requested-output boundary in fresh processes. Count remaining device, compute pipeline and driver overhead; do not subtract setup or infer a no-rise memory result from logical buffer sizes.

One candidate build and seed-1 oak/spruce comparisons are sufficient to decide whether these changes help. Keep the prior measurements as provenance. Broader seeds, browser adoption and GPU wood construction wait for this result. The 10x goal still requires work beyond foliage for oak, and 100 ms remains a stretch goal rather than a current claim.
