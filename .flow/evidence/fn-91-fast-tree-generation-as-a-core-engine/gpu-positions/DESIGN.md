# Compact position feasibility probe

The host approved this boundary before implementation. The default CPU builder and canonical prepared positions remain unchanged. The isolated `surface::compact` API repeats the canonical path validation, stable descending-radius run order, sampling and frames, but emits 64 bytes per ring plus angular/run metadata instead of positions, normals, coordinates or indices. Centres, frames and radius are converted to float32; angular cosine/sine retain CPU-precomputed values rounded to float32, while the lobed profile cosine runs in WGSL. This is ordinary float32 expansion, not double emulation.

One 64-lane workgroup emits each ring into packed xyz and writes endpoint caps. Dispatch uses the existing two-dimensional workgroup scheme. A second 64-lane group per run checks positions and procedural triangles and reduces bounds/status locally. A final group reduces run summaries; a 32-byte status readback completes the timed work. The index formula is the existing strip then interleaved-cap order. No full index/normal/coordinate/radius output is allocated. Ring descriptors, upload metadata and reduction scratch are released after completion; positions alone are the proposed resident output. This probe is test-only in the renderer and cannot be selected by real generation.

The diagnostic measures canonical preparation, drops it, then measures compact preparation, upload/dispatch and GPU validity/bounds completion separately. Four samples per fixture include a first observation plus three warm observations. CPU meshes, candidate bulk readback, repeated-output checks and numeric comparisons run afterwards, outside timing. Bounds must actually enclose all candidate positions. CPU-side f64 checks independently classify candidate triangle admission against the current criterion. Radius is recovered from candidate corners, and face/vertex normals are derived from candidate triangles, not from descriptor radii or frames.

Fixed mature screening bounds: all coordinates finite, zero newly collapsed faces, exact topology/counts/caps, maximum spatial error at most 50 micrometres and RMS at most 10 micrometres. Oak's combined compact/transfer/completion median must beat canonical preparation by at least 2x for each seed, and explicit simultaneous live allocations must not increase. No threshold is relaxed after observation. Degenerate/numeric-range edge outcomes are reported separately from mature qualification. This is neither first-frame measurement nor full parent qualification, and surface-contact integration remains a later gate.

Baseline: green via handoff, task .6 at ed0f6819 (core 19/19, renderer 14/14, Wasm build/browser checks). No repeated unchanged baseline suite was run. The task-specific base was persisted to `.flow/tmp/base_commit` before editing. The scratch Naga parser and validator passed the shader before the first Rust link.

The numeric-range regression prompted a host-approved guard: reject triangle points outside ±2^58 and edges outside ±2^59 before cross multiplication. This guarantees cross components below 2^119. The extreme-range spatial-error/collapse failure remains unsupported; it is not fixed or hidden by this arithmetic guard. Final scoped gates and one final guarded matrix pass; see REPORT.md.
