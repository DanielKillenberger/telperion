# R1: the cause, confirmed in Chrome (host, with the owner, 2026-10-09)

- **The run.** The owner ran Chrome on a fresh profile (`--user-data-dir=/tmp/chrome-gpu-probe --enable-logging=stderr --v=1`) at `http://localhost:5180/?species=european-beech&age=20`, against the release branch's harness after a machine restart, so every cache was cold.
- **The log.** The page loaded at 09:43:56. At 09:44:15, about 19 s later, the browser logged `gpu_process_host.cc:1130 GPU process exited unexpectedly: exit_code=512` and "The GPU process has crashed 1 time(s)". There were no NVIDIA kernel errors.
- **The crash report.** Crashpad wrote `Crash Reports/completed/3bc5f2a0-60d7-4562-8313-443c554ff967.dmp`. It is a `--type=gpu-process` dump whose crashing frame lies in `gpu/ipc/service/gpu_watchdog_thread.cc`, with the watchdog's crash keys present.

**Conclusion.** Chrome's GPU watchdog ended the GPU process during the first build, about 19 s in. That is consistent with the 12-17 s synchronous compile of `grow`, plus Chrome's own translation and the other pipelines, on the GPU process's main thread. R1 holds, and the async route stands.
