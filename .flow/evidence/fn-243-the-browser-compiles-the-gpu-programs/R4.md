# R4: the browser probe (owner, with the host, 2026-10-09)

- **The run.** The owner ran Chrome on a fresh profile with a cold cache against this branch's harness on port 5181, with GPU-process logging on as in R1. The log covers 10:42:58 to 10:48:22.
- **The result.** The beech, Laurelin and Telperion each loaded and drew, as the owner saw for themselves.
- **The log.** It has no `GPU process exited` line and no `exit_code`, so the GPU process did not crash. It does record watchdog histograms, `GPU.WatchdogThread.Event` (1 sample) and `GPU.WatchdogThread.Timeout` (20 samples, mean 0), but no watchdog kill. The histograms are recorded as written and are not interpreted here. The raw log stays in the host's scratchpad (`chrome-gpu2.log`) and is not committed.
- **The second load.** Not measured: the owner did not report how long the reload took, so R4's cache-hit timing is unrecorded.

**Conclusion.** With every pipeline created through `createComputePipelineAsync` at page load, a cold first load no longer ends the GPU process: R1's watchdog crash at about 19 s did not recur.
