# Why the hanging-twig dials are inert on the beech (code read, 2026-09-21)

Read-only investigation by a dispatched Explore agent; the host states the conclusion. Verified by reading unless marked inferred; the generator was not run.

**Cause.** `Curtain::new` zeroes the hang row unless the station has a descending structural ancestor: `pendant.rs:89` `let hang = if tip.is_some() { t.hang } else { 0.0 };`. `tip` comes from `Stations::floor` (`seed.rs:39-57`), which needs an ancestor edge pointing more than 30 degrees below horizontal (`direction.y < -0.5`, `seed.rs:44`). The beech's habit (`lateral_pitch 28`, `pitch_variation 6`, `rise_primary +0.1`, `rise_secondary 0.0`, `lateral_orders 3`, no bias, no attractor cloud) cannot produce such an edge: the worst case is about 113 degrees from vertical, `y ≈ -0.39` (inferred arithmetic from `scaffold.rs:300-304, 329-333, 376-386`). With hang forced to 0 every curtain method is the exact identity (`advance.rs:148, 173, 192, 197, 272`, `planner.rs:109`), which is why the stills are byte-identical and the node count does not move. `hangs_at` at `pendant.rs:77`, the row a reader would suspect, is passed, not failed.

**Not the cause.** The overlay reaches the twig rows (`params.rs:80`, `overlay` at `:339-357`), nothing resets them (`presets.rs:242`), both examples overlay the whole family, and the local twig layer does run for the beech (`branching/specimen.rs:244-266`).

**The coupled set.** Hanging turns on only when `/skeleton/twigs/hang > 0` AND `/skeleton/habit/riseSecondary` is negative enough to give a descending ancestor: about −0.40 for typical order-3 axes and about −0.71 for order-2 (inferred; the right check is a probe counting edges with `direction.y < -0.5` per preset and seed). To be visible it also needs `pendulousLength` well above the default 0.25 m (the birch uses 3.0), `sag` above 0, and `curtainDrop` with `curtainClearance`; `maxDroop` is only a ceiling. The two shipped presets that hang both pair `hang` with a strongly negative `rise_secondary` (silver birch −0.85 with hang 2.4, sag 1.0, pendulous length 3.0, curtain drop 0.6; Norway spruce −0.8 with hang 1.0).

**Consequence for the loop.** No single-dial move can reach hanging foliage on the beech; a bundle across habit and twig rows can. This is a tuning coupling, not yet a proven capability gap.
