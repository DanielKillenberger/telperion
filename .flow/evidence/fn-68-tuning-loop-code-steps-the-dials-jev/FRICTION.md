What would remove it: the production command emitting replay cases from its own dispatched receipts (so hashes and provenance are code-derived, never re-typed), and a provenance vocabulary in `joint::Input.condition` that can state "reconstructed" or "reframed" instead of a single hardcoded literal that only a live production capture can satisfy.

## 2026-09-21 — Vision spend cannot be imported through the contract built for model spend
