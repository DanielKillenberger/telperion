# Tree space: the silver birch as a point

## Goal & Context

The silver birch (Betula pendula) as a point in the tree space, through the engine, so the preset `silver-birch` builds again on the engine path (fn-198 refuses it by name until then) and killenberger.com's grove can draw on a released package (fn-198 FIELD-PATH.md: nearly every grove contains a birch). Owner, 2026-10-07: "build the 4 missing tree species. They don't need to look the same as today's harness implementations. Ideally they look better" (flow memory: the four missing species). The bar is a mature open-grown silver birch as it reads in reference photographs: a slender, often curving white-barked stem, a narrow ovate crown, long fine pendulous outer shoots ("weeping" twigs on ascending limbs), and small diamond leaves on short shoots; not today's preset.

## Programme

One species per spec (AGENTS.md). Follow the tree-space programme (`docs/tree-space.md`): stand on botany, invent the space; the species judged as phase C and D judged theirs; the method in `docs/species-onboarding.md` and `docs/species-pipeline.md` where they apply to an engine species. Model the specification on fn-193 to fn-196 (MODEL-*.md in their evidence): architectural model and sources, values as a point in the space, gates, walks.

## Edge Cases & Constraints

- **Stand on botany:** mechanisms reproduced against sources; external code and data never copied. [user]
- **Errors, not fallbacks;** every setting by degree; presets are values (`docs/principles.md`). [principles]
- **Judging:** the host views every still first; the species passes only when the host is confident it reads as a silver birch beside its reference photographs and Astra, on the same sheet independently, agrees. [user]
- **A generator gap** the birch needs (for example pendulous shoots by their own weight, white bark appearance) is its own spec this one depends on; the host decides gaps. [AGENTS.md]
- **Agents:** design judgments go to the host; friction to this spec's FRICTION.md. [AGENTS.md]

## Acceptance Criteria

- **R1:** MODEL-BIRCH.md: the birch's architecture (Hallé and Oldeman model), its long and short shoots, pendulous outer shoots, growth rates and form at 20 to 80 years, each value cited to a source and screened per `docs/typesafe.md` where Jev applies.
- **R2:** The birch's values as engine species rows in the `silver-birch` preset (fn-198's /space rows); it builds through the pipeline natively and in the harness; the refusal is lifted.
- **R3:** The gate: host confident and Astra agrees on a sheet of stills (seeds 1, 7 and 42 at ages 40 and 80, bare and in leaf, hero and crown views) beside reference photographs.
- **R4:** A walk from the beech to the birch as still strips with no visible pop; the passed beech, spruce, oak and palm sheets unchanged in look.
- **R5:** killenberger.com's field path for the birch measured as FIELD-PATH.md did (site unchanged).
- **Wrong-path stop:** two rejections (host or Astra) naming the same trait after a change aimed at it.
