# Oak references (Quercus robur stand-in, Quercus garryana where available)

## Photographic set (fn-188)

Real photographs from Wikimedia Commons, gathered for fn-188 to judge renders at five scales: S1 whole tree leafless, S2 whole tree in leaf, S3 mid-crown limbs leafless, S4 twig spray leafless, S5 leafy spray. Each file is resized to at most 2000 px on the long side; the licence and attribution are the Commons file page's. The catalogue's oak is Oregon white oak (*Quercus garryana*). Commons has no clean, frontal, leafless, open-grown *Q. garryana*, so pedunculate oak (*Q. robur*) stands in where needed; each file's name and entry say which species it shows. The catalogue's existing oak references (OSU Landscape Plants, USFS) carry no redistribution licence here, so none is copied.

`S1-robur-field-november.jpg`: S1, whole tree, leafless. *Quercus robur*. An isolated field oak, Sedlčánky, Czechia, November, leafless.

A single bole to about a third of the height, then several ascending-spreading limbs in a rounded crown slightly wider than tall. Frontal, whole crown against the sky.
