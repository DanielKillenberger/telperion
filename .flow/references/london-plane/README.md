# London plane reference

`schutzenmattpark-basel-2026-09-27.jpg`: a mature London plane (*Platanus × hispanica*) in Basel's Schützenmattpark, photographed by the owner on 2026-09-27; the owner's own photograph, committed with the owner's consent for use as a species reference.

- sha256: `789b465ef5a96911c479589f145fa3c09840c2152c586296e4e6c03ee146408b`
- 1500 × 2000, whole tree in leaf, from the ground, backlit.
- What it shows: a short trunk that forks low into three or four leaders of near-equal girth, each carrying a few thick secondary limbs that stay thick far out and break into dense twigs at the crown's edge (fn-170, fn-177).

## Photographic set (fn-188)

Real photographs from Wikimedia Commons, gathered for fn-188 to judge renders at five scales: S1 whole tree leafless, S2 whole tree in leaf, S3 mid-crown limbs leafless, S4 twig spray leafless, S5 leafy spray. Each file is resized to at most 2000 px on the long side; the licence and attribution are the Commons file page's. Pollarded and pruned planes, which are most city planes, were rejected. Where the description says only "platanus", the hybrid identity is the file's Commons category (Platanus × hispanica).
