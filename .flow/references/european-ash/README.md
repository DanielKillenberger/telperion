# European ash references

## Photographic set (fn-188)

Real photographs from Wikimedia Commons, gathered for fn-188 to judge renders at five scales: S1 whole tree leafless, S2 whole tree in leaf, S3 mid-crown limbs leafless, S4 twig spray leafless, S5 leafy spray. Each file is resized to at most 2000 px on the long side; the licence and attribution are the Commons file page's. The catalogue's existing ash references (OSU Landscape Plants) carry no redistribution licence, so none is copied here.

`S1-bobrowniki-monument-winter.jpg`: S1, whole tree, leafless. A leafless roadside ash listed as a natural monument (pomnik przyrody), Bobrowniki Śląskie, Poland, March.

A single tall bole forking into a few strong ascending limbs; an irregular, open crown with drooping secondary branches whose ends turn up.
