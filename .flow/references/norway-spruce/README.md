# Norway spruce references

## Photographic set (fn-188)

Real photographs from Wikimedia Commons, gathered for fn-188 to judge renders at five scales. Spruce is evergreen, so the leafless scales are adapted: S1 and S2 are two open-grown whole trees of different branch habit, S3 whorl branches with their branchlets, S4 a shoot tip with buds and needles, S5 a branch spray of second- and third-order shoots. Each file is resized to at most 2000 px on the long side; the licence and attribution are the Commons file page's. The catalogue's existing spruce references (OSU Landscape Plants) carry no redistribution licence, so none is copied here.

`S1-lawn-solitary-comb.jpg`: S1, whole tree, open-grown (comb habit). A solitary Norway spruce on a lawn (Italian Wikipedia, "Portamento", habit).

A straight single stem to the leader, narrow-conical crown with readable tiers of whorl branches; main branches near-horizontal and upturned at the tips, with second-order branchlets hanging from them (comb type).

`S2-beskid-meadow-brush.jpg`: S2, whole tree, open-grown (brush habit). A lone spruce on an open mountain meadow, Krawców Wierch, Beskid Żywiecki, Poland, May.

A broad, dense crown from ground to a sharp leader; short branches held stiffly near-horizontal (brush/flat type), a full skirt to the ground.

`S5-branch-spray.jpg`: S5, branch spray. A spruce branch in Taevaskoda, Estonia, October.

An arching main axis carrying second-order shoots that carry third-order shoots in one flattish spray; needles all round each shoot; paler young growth at the shoot ends marks the shoot hierarchy.
