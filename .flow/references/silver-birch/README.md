# Silver birch references

## Photographic set (fn-188)

Real photographs from Wikimedia Commons, gathered for fn-188 to judge renders at five scales: S1 whole tree leafless, S2 whole tree in leaf, S3 mid-crown limbs leafless, S4 twig spray leafless, S5 leafy spray. Each file is resized to at most 2000 px on the long side; the licence and attribution are the Commons file page's. The catalogue's existing birch references (OSU Landscape Plants) carry no redistribution licence, so none is copied here.

`S1-newforest-heath-winter.jpg`: S1, whole tree, leafless. An open-grown silver birch on a heath slope, New Forest, England, December.

A single white bole carrying an excurrent leader into an ovoid crown; ascending lower limbs with fine drooping twig tips at the periphery. Whole tree in frame, front-lit.
